# Azure Infra & Entra ID Süddeutschland Meetup - Öffentliches Archiv

Dieses Repository enthält Präsentationen, Bilder, Karten, Logos und weitere Materialien aus den **Azure Infra & Entra ID Süddeutschland Meetups**.

Ziel des Meetups ist der Austausch zwischen Azure-, Infrastruktur-, Identity- und Security-Interessierten im süddeutschen Raum. Der Fokus liegt auf praxisnahen Themen rund um Azure Infrastructure, Microsoft Entra ID, hybride Cloud-Architekturen, Security, Governance und Community-Austausch.

## Meetup-Fokus

**Azure Infra & Entra ID – aus dem Süden, für den Süden.**

Das Meetup richtet sich an Community-Mitglieder, IT-Pros, Architekten, Consultants und Entscheider aus Baden-Württemberg und Bayern. Im Mittelpunkt stehen regionale Nähe, fachlicher Austausch und konkrete Erfahrungen aus Projekten und Praxis.

Schwerpunkte:

- Azure Infrastructure
- Microsoft Entra ID
- Identity & Security
- Hybrid Cloud
- Governance & Permission Management
- Architektur, Migration und Modernisierung
- Community Networking
